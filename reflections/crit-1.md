# C1 — Forgotten web

## What was the breakthrough that moved the work forward?

The main breakthrough was developing a much better understanding of the course website and its requirements while trying not to miss important details. I successfully completed the onboarding process and became more familiar with using Claude Code. I also learned that, when I am uncertain about course-related requirements or workflows, I can ask Claude directly through the terminal instead of searching through the course website page by page.

In particular, the COMP4020 plugin can provide answers based on the actual course materials and context. This makes it easier to find relevant information and significantly improves my efficiency. However, I also understand that I should not rely entirely on AI. Read the official course materials toverify important information is also important.

## What did this work change about who I want to be as a software developer?

Previously, I was not very willing to allow AI directly to execute tasks and modify code. I mainly used conversational AI tools such as ChatGPT or Claude to ask questions, and then I wrote, ran, and debugged the code myself.

Crit1 made me use new development tools and workflows. Allowing Claude Code to inspect and modify my project directly improved my efficiency. It also increased my confidence in completing this course and in using AI-assisted tools in my future software development work.

At the same time, this experience revealed a potential weakness in my current workflow. When Claude Code completes a task for me, I may not fully understand every part of the work it has performed. Compared with asking ChatGPT or Claude for guidance and then implementing each step myself, using Claude Code can make the development process feel less transparent. In some cases, I was not completely aware of the technical details or implementation decisions that Claude used to turn my ideas into a working result.

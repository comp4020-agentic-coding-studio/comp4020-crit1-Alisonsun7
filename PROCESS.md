# Process overview

## What I built

**The Sable Den** — The website is designed to resemble a personal GeoCities homepage from 1996. It features a tiled starfield background, magenta and cyan ridge borders, a scrolling marquee, and an under-construction sign with a barber-pole effect. The entire site is built with plain HTML and CSS, with no JavaScript used anywhere.

The project does more than imitate the visual style of the early web. Its content and presentation are intentionally sincere rather than ironic. The site is imagined as being created by an enthusiast who will probably never see a living sable in person. Instead, the creator builds the website from other people's fieldwork, the history of the sable fur trade, and an ongoing correspondence. As a result, the site is not only a recreation of an old-fashioned web aesthetic, but also a believable and personal expression of genuine interest in the subject.


## The moments that mattered

### 1. Choosing the design style and correcting the topic

I actively chose to design the website as a 1996-style GeoCities personal homepage. However, an unexpected problem occurred during the initial development. Although I had provided Claude with a Wikipedia link about the sable, the website it generated was called The Moth Room and focused entirely on moths.

Claude later explained that moths were well suited to the style of a 1996 GeoCities hobbyist homepage, since they represented the kind of niche interest that someone might realistically have created a personal website about at that time. Nevertheless, this did not match my original requirement. I only discovered the mismatch through manual inspection, after which I gave Claude a new instruction to replace the moth-related content with information about the sable.

Cited: [`edc7a1b`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit1-Alisonsun7/commit/edc7a1b) — the rewrite from moths to *Martes zibellina*.

### 2. Removing an unnecessary feature

In the initial design, I noticed that some elements were not necessary. For example, the homepage displayed the text, "You are visitor number 0001862." I did not think it added meaningful value to the website. Therefore, I asked Claude to remove it.

Cited: [`0d880e7`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit1-Alisonsun7/commit/0d880e7) — dropping the visitor counter.

### 3. Distinguishing factual and fictional content

I also noticed that some of the content generated by Claude did not come from the factual information I had provided. At the same time, these invented details felt believable and matched the style of a 1996 personal homepage very well.
To avoid presenting fictional material as fact, I asked Claude to identify the non-factual content and add the label "(fictional)" after it. This allowed the website to retain its period-appropriate narrative style while clearly distinguishing verified information from invented content.

Cited: [`c137191`](https://github.com/comp4020-agentic-coding-studio/comp4020-crit1-Alisonsun7/commit/c137191) — separating Wikipedia fact from invented flavour text.
